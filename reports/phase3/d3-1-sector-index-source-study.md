## 三、数据质量检查（关键）

对中证官网 10 个指数逐条做质量检查（证据 `sector_index_history.json` 的 `quality` 字段）：

| 检查项 | 结果 |
|---|---|
| 日期唯一性 | 10/10 全部 463 个日期唯一，无重复日期、无连续重复日期 |
| OHLC 逻辑（high≥max(o,c), low≤min(o,c)） | 10/10 违规数 = 0 |
| OHLC 缺失行 | 0 |
| **跨"不同日期"OHLC+量+额完全相同的异常组** | **10/10 各有 1 组：`2023-01-01` 与 `2023-01-03` 完全相同** |
| 字段检测 | 成交量=volume（"成交量"列）、成交金额=amount（"成交金额"列），均存在 |
| 成交金额单位 | **unknown**（响应/文档均未标注；样本值如 159.01、126.88） |

### 3.1 系统性异常（决定性发现）

**全部 10 个中证行业指数都出现 `2023-01-01`（元旦节假日）与 `2023-01-03` 行情完全相同**——这与 D3-0 第四轮在 000928 上发现的 `2024-01-01/01-02` 异常**同构**，证明这是**中证 `csindex` 接口的系统性数据质量问题**（节假日占位/重复记录），**不是 000928 个案，也不能因"能返回数据"就认定生产级**。

### 3.2 异常来源定位

- 上一轮已证 000928 原始 HTTP 与 DataFrame 一致（异常源自中证上游，非 AKShare 解析）。
- 本轮 `supplement_coverage_bj_newyear.json` 的新浪对比：`sh000932` 历史中 **无 2023-01-01、无 2024-01-01 记录**——即新浪源**没有**中证的节假日异常记录。
- **结论**：节假日异常是**中证 csindex 源特有**，新浪源在该点更干净。

### 3.3 跨源交叉比对（3 指数要求）

跨源比较样本共 3 个指数：**1 个新浪成功、2 个新浪失败**——000932 新浪成功（可交叉）；399986、399975 新浪失败（无法交叉，失败记录如实保留，未伪造）。

对 000932 的 **462 个共同交易日**按原始精度重算（证据 `sector_index_history.json` 的 `cross_source[000932]`，含 `all_common_date_diffs` 全量 462 日明细可复核）：

| 指标 | 值（原始精度） |
|---|---|
| 共同交易日数 | 462 |
| 最大绝对偏差（收盘价） | 0.005000000001018634（约 0.005） |
| 最大相对偏差 | 3.8088636058889944e-05 %（约 0.000038%，非 0） |
| 平均绝对偏差 | 见证据 `mean_abs_diff`（非 0，可复核） |
| 收盘价完全相等的天数 | 44 / 462 |
| 是否完全一致 | **否**（`fully_identical=false`） |
| 比较精度 | 中证收盘最多 2 位小数、新浪最多 3 位小数（两源精度不同） |

| 指数 | 对比源 | 共同日期数 | 交叉结论 |
|---|---|---|---|
| 000932 800消费 | 中证 vs 新浪 | 462 | 高度接近但**非完全一致**：最大相对偏差约 0.000038%，仅 44/462 天收盘价严格相等 |
| 399986 中证银行 | 中证 vs 新浪 | — | 新浪 error，无法交叉（unavailable，失败记录如实保留） |
| 399975 证券公司 | 中证 vs 新浪 | — | 新浪 error，无法交叉（unavailable，失败记录如实保留） |

**口径纠正（P2-01）**：此前"0.0%（完全一致）"的表述不成立——0.0% 是**最大相对偏差四舍五入到 4 位小数**的结果（真实值约 3.81e-05%），且只有 44/462 天收盘价严格相等。两源数据高度接近但不完全相等，**不得描述为"完全一致"**。剔除非交易日异常后两源数据可靠这一方向性结论仍成立，但须按上述原始精度表述。另有 2 个指数因新浪源无数据无法交叉 → 交叉覆盖 1/3，未达"3 指数全部交叉"的理想要求（标注 unavailable；失败记录如实保留，未伪造交叉结果）。

## 五、结论（行业指数）

- **已证实**：中证官网可取 10/10 行业指数各 463 行历史（≥100 交易日）；字段含 OHLC/成交量/成交金额（vol=成交量, amount=成交金额）；日期唯一、OHLC 逻辑无违规；但 10/10 存在节假日重复异常。本轮已为 10 个指数补存完整原始响应正文与完整标准化数据（SHA256 可核），质量统计可从标准化数据重算。新浪对 7 个行业指数可取更长历史且无中证式节假日异常（另 3 个失败：399986/399975/399998）；000932 两源 462 共同交易日收盘价高度接近但**非完全一致**（最大相对偏差约 3.81e-05%、44/462 天严格相等，详见 3.3）。
- **未证实**：腾讯/东财对行业指数的稳定历史能力（腾讯仅验证宽基、东财网络不可达）。
- **unknown**：成交量/成交金额单位（中证与新浪均未标注）；3 个指数中 2 个因新浪无数据无法交叉。
- **unavailable**：中证 csindex 作为 V1.0 生产源（质量验证未通过，维持前轮判定）；3 指数全交叉（仅 1 个可交叉）。
- **推测**：中证节假日异常为上游占位数据生成逻辑所致（有 HTTP 一致性证据，但根因无官方说明）。

**行业指数结论**：**尚无"质量合格 + 单位明确 + 可持续"的行业指数历史源可作为 V1.0 生产候选**。中证质量未通过；新浪质量较好但成交额字段缺失/单位不明、行业覆盖需逐个确认；跨源交叉仅 1/3 完成。
