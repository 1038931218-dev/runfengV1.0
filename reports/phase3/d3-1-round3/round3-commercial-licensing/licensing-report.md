# D3-1 第三轮 · 任务D：数据商业授权核实

- 生成时间：2026-11-22（GMT+8）
- 任务性质：只读调查；本文件为**分析结论**，原始网页响应见本目录 `*_raw.html` / `*_raw.txt` 及 `*_fetch.json`
- 核心原则：技术可访问 ≠ 商业授权；找到商业服务入口 ≠ 当前免费接口已获授权；无禁止条款 ≠ 获得授权

## 一、新浪（当前用于行业分类的免费网页接口）

- **数据源及运营主体**：新浪网 / 新浪财经（北京新浪互联信息服务有限公司等），免费网页接口 `vip.stock.finance.sina.com.cn`、`hq.sinajs.cn`（AKShare 的 `stock_sector_spot`、`stock_sector_detail`、`stock_zh_index_daily`）
- **适用协议**：新浪用户协议（2025-09-17 生效），第 2.7/6.1/6.2/10.1 条（前两轮已取证，原始响应见第一轮证据）
  - 6.1/6.2：未经书面许可，不得复制、读取、采用数据用于商业用途
- **官方商业渠道（本轮新证据）**：新浪财经智研平台 `zyhub.finance.sina.cn`
  - 提供官方 MCP Server / API 服务，以 **APIKey** 授权，"合规金融数据"，覆盖 20+ 年历史、行业/概念/指数成分、行情；"免费申请 API Key"、需"调用权限和配额"（原文见 `sina_zyhub_help_raw.txt` 及本轮 WebFetch 记录）
  - 这是与 AKShare 所用免费网页接口**不同的数据通道**，不能自动继承其授权
- **分项结论**：

| 维度 | 结论 | 说明 |
|---|---|---|
| 商业使用（当前免费接口） | 明确禁止（协议6.1/6.2） | 未经书面许可不得商用 |
| 存储 | UNKNOWN | 协议未逐条定位到存储条款 |
| 对外展示 | UNKNOWN | 同上 |
| 二次加工 | UNKNOWN | 协议有"不得加工"倾向但未取得逐字条款 |
| 历史数据使用 | UNKNOWN | 免费接口无明确授权 |
| 官方商业授权渠道 | **存在**（智研平台APIKey） | 但是否覆盖 AKShare 所用接口、费用、条款细则需向新浪确认 |

- **尚需确认**：智研平台 API 是否覆盖行业分类/历史成分；APIKey 是否允许商业产品内部使用、存储、对外展示、向客户提供；报价与授权期限。
- **预计费用**：UNKNOWN（官方页面称"免费申请 API Key"，但商业授权报价未找到）。

| 维度 | 结论 | 说明 |

| 商业使用 | UNKNOWN | 未找到明确适用于本接口的授权或禁止条款 |

- **尚需确认**：本接口的实际运营主体；适用的正式服务协议及版本；商业使用/存储/二次加工/对外展示授权；官方商业 API 渠道。
- **预计费用**：UNKNOWN。

## 三、官方数据源（中证指数 / 上交所 / 深交所）

- **中证指数有限公司**：存在正式商业数据服务通道（官网数据服务页、`数据文件服务规范（资讯商专用）V1.3.22`、《常见问题》第6条营销服务部 `service@csindex.com.cn`）。官方历史行情接口本轮实测可用（见任务C）。但**本项目是否已取得授权 = 否**（无合同、无书面答复）。
- **上交所 / 深交所**：官网提供年度休市公告与公开行情，未找到本项目所需的商业数据授权凭证。
- **分项结论**：商业使用/存储/对外展示/二次加工/历史数据使用 = 均为 **UNKNOWN**（存在商业渠道，但未取得授权文件）；费用 UNKNOWN（无可靠官方报价）。

## 四、总体判断

**新浪、腾讯、官方源三者均无法证明本项目已取得可支持商业产品使用的合法授权。**

- 新浪当前免费接口：协议明确限制商用 → **明确禁止（未经书面许可）**
- 腾讯当前接口：**UNKNOWN**（协议适用性未证实）
- 官方源：存在商业渠道但未签约 → **UNKNOWN**（未授权）
- 新浪智研平台是潜在合规替代路径，但需另行申请、核实覆盖范围与商业条款。

商业授权仍为 D3-1 的**硬性阻塞项（BLOCKED）**，不因本轮调查而解除。
