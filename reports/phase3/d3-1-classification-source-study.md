## 一、研究范围与"目录≠映射"纪律

本轮分别验证四件事，**严格不混淆**：①行业分类目录（类目编码/名称/层级）；②股票代码→行业映射；③分类标准及版本；④分类生效日期与变更历史；⑤当前有效分类；⑥全市场覆盖率。

> 关键纪律（承接 D3-0）：**接口能返回行业目录，绝不等于它能提供全市场股票成分映射**。例如 `stock_industry_category_cninfo` 返回 294/577 行类目目录，但无个股代码；`sw_index_second_info` 131 行同样是目录。

## 二、各数据源实测

### 2.1 巨潮资讯（cninfo）

| 接口 | 性质 | 实测结果 | 判定 |
|---|---|---|---|
| `stock_industry_category_cninfo(symbol='巨潮行业分类标准')` | 分类目录 | 294 行，字段：类目编码/名称/终止日期/行业类型编码(008002)/父类编码/分级(0-4级) | **已证实可用（目录，非映射）** |
| `stock_industry_category_cninfo(symbol='证监会行业分类标准')` | 分类目录 | 577 行，同结构 | **已证实可用（目录，非映射）** |
| `stock_industry_change_cninfo(symbol, start_date, end_date)` | 个股变更历史 | 30 样本中 25 只成功（沪深），含行业中类/大类/次类/门类 + 分类标准编码 + 变更日期 | **已证实可用（历史分层完整，但时效止于 2022-07）** |
| `stock_profile_cninfo(symbol)` | 个股公司概况 | 含"所属行业"名称字段（如"货币金融服务"），30 样本 25 只成功；接口**未直接返回分类标准编码、版本、生效日期** | **已证实可用（当前单级行业名称）；但 `classification_standard=unknown`，不认定为某一具体标准** |

**巨潮标准目录层级示例**（`008002` 巨潮行业分类标准）：类目 `Z`→`Z01 能源`(1级)→`Z0101 能源`(2级)→`Z010101 能源设备与服务`(3级)→`Z01010101 能源设备`(4级)——**层级完整、有编码、有终止日期字段**。

**巨潮 change 历史**：对 `601398` 返回 6 条变更记录，含四级行业 + 分类标准编码 + 变更日期，可识别历史变更；但历史数据止于 2022-07（承接 D3-0 时效结论：2024 仅中上协标准 1 条、2025/2026 空响应）。

### 2.2 申万行业分类

- `sw_index_second_info()` 131 行、`sw_index_third_info()` 336 行：行业目录（含层级，无个股代码）——**已证实为目录**。
- `sw_index_third_cons(symbol)` 个股成分映射：承接 D3-0 第三轮，两次调用失败（Length mismatch / No tables found）——**未证实**。
- `stock_industry_clf_hist_sw()` 全部行业分类变动历史（xls）：本轮实测 **SSL 证书验证失败**（`CERTIFICATE_VERIFY_FAILED`）——**未证实（网络/证书障碍）**。

**结论**：申万能取行业目录，但**个股成分映射与历史分类在本环境均未稳定取得**。

### 2.3 中证行业分类

- `index_csindex_all()`：2386 个指数清单，其中资产类别=股票 1516 个、行业类关键词命中 397 个——这是**指数清单，不是股票行业映射**。
- `index_stock_cons_csindex(symbol)`：指数成分股目录（当前快照，非行业分类、非历史成分）。
- 中证"行业分类标准"本身：**未取得独立的股票→行业映射接口**（指数成分≠行业分类）。

### 2.4 中国上市公司协会（中上协）

- 承接 D3-0：巨潮 change 接口中 008001 中上协标准在 2024-02-08 有 1 条记录——疑为换代标准，但**样本量不足、无全市场映射** → **unknown/推测**。

## 四、全市场覆盖率（以 5580 为分母）

**分母重新确认**：`full_universe_code_audit.json`（采集于 2026-11-21 08:45，当日）三市并集 5580 = 东财 5580、集合逐只相等、sets_identical=true——**分母仍适用**。

**覆盖率实测**（`supplement_coverage_bj_newyear.json`）：从 5580 集合随机抽 200 只，逐只调 `stock_profile_cninfo`：

| 指标 | 值 |
|---|---|
| 分母（全市场有效A股） | 5580（已证实，集合级） |
| 样本量 | 200 |
| 成功映射 | 200 |
| 空/错误 | 0 |
| 样本覆盖率 | **100.00%** |
| 全市场精确覆盖率 | **unavailable**（未逐只跑完 5580，标为样本估算） |

**口径纪律**：此处的 100% 是 **profile 接口对 200 样本"所属行业"字段的非空映射率，且该字段 `classification_standard=unknown`**（未返回标准编码/版本/生效日期，未认定为证监会行业分类）。它**不是**"巨潮标准 008002 的全市场覆盖率"，也不是任何已明确标准的覆盖率。巨潮 008002 标准的全市场覆盖率**未实测**（change 接口按单只调用、历史止于 2022，无法给出当前全市场 008002 覆盖）→ **unavailable**。**不得把 profile 的"所属行业"样本映射率与巨潮 008002 合并或互相冒充为覆盖率**。

**多重分类/标准冲突**：本轮未逐只统计同一股票在巨潮多标准下的分类冲突数 → **unknown**。

## 五、分类方案建议

| 维度 | 建议 | 依据 |
|---|---|---|
| **V1.0 主分类标准** | **巨潮行业分类标准（008002）**为候选，但**暂不冻结** | 唯一同时具备完整目录层级（4级+编码+终止日期）与个股历史变更（多标准+变更日期）的源；但当前分类完整性/时效未证实 |
| **可选辅助参考** | `stock_profile_cninfo` 的"所属行业"名称字段作当前行业参考（`classification_standard=unknown`） | 200 样本 100% 非空映射，但无编码/无标准标识/无版本/无层级/无生效日期/无历史，且未认定为证监会行业分类；仅可作辅助参考，不与 008002 合并覆盖率 |
| **版本管理** | 以 `classification_standard + classification_version + effective_from` 三元组标识；008002 目录的"终止日期"可作版本边界 | 巨潮目录含终止日期字段 |
| **变更历史保存** | 用 change 接口的"变更日期 + 分类标准编码 + 四级行业"做 SCD Type-2（生效区间） | change 接口提供所需字段，但时效止2022需解决 |
| **失效/未知处理** | 过期记录标 `stale`、无记录标 `unknown`，均不计入有效覆盖分子 | 承接 D3-0 时效结论 |
| **禁止事项** | 不混用多标准、不用行业目录条数代替股票覆盖率、不用名称相似认定标准一致 | 本轮与 D3-0 纪律 |

**不能为尽快启动而混合标准**：008002（历史分层完整但时效旧）与 profile"所属行业"名称（当前但无编码、标准 `unknown`、无历史）不构成可核对的同标准体系，V1.0 必须选定其一为主、另一为辅，不得拼凑覆盖率，也不得把两者映射率相加或等同。

## 六、结论（分类数据）

- **已证实**：巨潮有完整分类目录（008002 四级/证监会标准目录 577 类）；profile 对沪深北 920 段"所属行业"字段样本映射 200/200（字段非空）；change 接口有多标准历史分层但止于 2022；申万/中证只有目录或指数成分，无稳定个股行业映射。
- **未证实**：申万个股成分映射与历史分类（接口失败/SSL）；中证独立行业分类映射；巨潮 008002 当前全市场覆盖率与时效。
- **unknown**：北交所旧→新代码映射、同一股票多标准冲突数、profile"所属行业"字段的分类标准编码/版本/生效日期/时效性（`classification_standard=unknown`，未认定为证监会行业分类）。
- **unavailable**：巨潮 008002 全市场精确覆盖率（未逐只跑 + 历史止2022，无法给出当前有效覆盖）。
- **推测**：中上协 008001 为换代标准（样本不足）。

**分类数据结论**：**尚未有"标准明确 + 当前有效 + 全市场覆盖 + 历史可追溯 + 时效合格"五项齐备的分类数据方案**。profile 当前映射覆盖好但无标准编码/历史/时效；巨潮标准分层好但时效旧、当前覆盖未证实。这是 D3-1 的核心阻塞。
