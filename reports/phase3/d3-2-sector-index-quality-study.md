## 一、任务书七问逐项回答

### 1. 中证重复异常的底层原因——已定位到上游
`csindex_anomaly_rootcause`：对 000928 取 20230101-20230110，捕获底层 HTTP 原始正文（HTTP 200，body_sha256 `7511f528e6a62283...`，body_len 2430）。原始 JSON 的 `data` 数组明确含两条记录：
- `tradeDate=20230101`：`close=2399.25`、`tradingVol=8.044845E8`、`tradingValue=59.69`
- `tradeDate=20230103`：`close=2399.25`、`tradingVol=8.044845E8`、`tradingValue=59.69`

**2023-01-01 是元旦（非交易日），却被填入与 01-03 完全相同的行情。** 原始 HTTP 正文与 DataFrame 一致。

### 2. 是接口返回、日期映射还是交易日处理错误——接口返回（上游）
- 不是 AKShare 解析错误：原始 HTTP 正文（未解析）已含两条相同记录。
- 不是日期映射错误：`tradeDate` 字段在原始 JSON 中就是 20230101 与 20230103。
- 是**上游数据本身**在非交易日填充了重复占位记录。
> 根因：中证 `csindex-home/perf/index-perf` 上游在非交易日（元旦）返回了与前一日相同的行情记录。具体生成逻辑（占位/复制）无官方说明，标**推测**；但"异常源自上游接口返回"是**已证实**。

### 3. 其他行业指数是否同类异常——已证实系统性
`csindex_extended_anomaly` 对 6 个新指数（000933 800医药、000934 800金融、000822 全指材料、000986 全指能源、000811 细分有色、399808 中证新能）取元旦区间，**6/6 全部**出现 `2023-01-01` 与 `2023-01-03` 的 `close/tradingVol` 完全相同。结合 D3-1 的 10/10，中证异常是**跨指数的系统性质量问题**，非个案。

### 4. 能否找到质量更可靠的行业指数历史源——腾讯是潜在替代
`tencent_index_probe`：腾讯 `stock_zh_index_daily_tx` 对 4 个代码全部可用（sz980017 640 行、sh000819 3772 行、sh000932 4223 行、sz399986 2739 行），字段 `date/open/close/high/low/amount`，日期至 2026-11-20。
> 修正此前"腾讯仅验证宽基、未验证行业指数"的表述：腾讯对行业指数代码可用，是潜在替代源，但"有成交额(amount)无成交量(volume)"，需进一步验证行业覆盖完整性与单位。**未证实其适合生产**。

### 5. 新浪 7 个成功指数的覆盖与连续性——5 个持续更新，2 个历史中断
`sina_continuity`：7 个成功指数均 OHLC 可取、无中证式元旦异常（has_2023_01_01=false）；但：
- 更新至 2026-11-20 的 5 个：000932、000991、000819、000928、000986（最长 4223 行）。
- 历史中断的 2 个：000807 食品饮料（止于 2018-12-25）、000808 医药生物（止于 2021-02-04）。
- 相邻记录最大自然日间隔 10-11 天（春节等长假）。
> 新浪 7 成功≠7 个都持续更新到当前；各指数历史长度不一，需逐个确认。

### 6. 腾讯是否存在可验证的行业指数历史接口——已证实可用
见第 4 问，4/4 代码可用。字段有 amount 无 volume。

### 7. 成交量/成交额单位能否确认——仍 unknown
`unit_confirmation`：AKShare `stock_zh_index_hist_csindex` 的 docstring 明确提示"只有收盘价，正常情况下不应使用该接口"，但**全文无任何"单位/元/手/股"关键词**（csindex_unit_keywords=[]）；接口返回字段 `tradingVol`/`tradingValue` 无单位标注；新浪/腾讯亦无单位说明。
> **结论：成交量/成交额单位维持 unknown，不得臆测量纲。`amount_available` 保持 false。**

## 四、D3-2.4 结论

- **已证实**：中证元旦异常源自上游 HTTP 原始正文（非解析/非日期映射）；跨 16 个指数系统性存在；腾讯行业指数接口可用；新浪 7 成功中 5 个持续更新至 2026、2 个历史中断；单位无官方说明。
- **推测**：上游非交易日占位数据生成逻辑（无官方根因说明）。
- **unknown**：成交量/成交额单位；腾讯源生产适用性。
- **unavailable**：中证作为 V1.0 生产源（质量未通过，维持判定）。
- **行业指数源质量状态：BLOCKED/UNKNOWN（未解除）**——无"质量合格 + 单位明确 + 持续更新"三齐备的生产源。
