## 〇、方法论与已知工具限制

1. **不把接口返回成功等同于数据完整**：例如新浪 spot 返回 5579 行，仅证明"取到该快照"，其是否等于全市场由交易所官网名单交叉印证后方可下结论。
2. **严格区分三类数据**：行业目录（行业代码/名称/层级）、板块成分股（板块→个股映射）、板块指数日线（OHLCV 历史序列）互不替代。
3. **底层 HTTP 证据**：对 AKShare 调用做 `Session.request` monkey-patch，捕获 URL/参数/HTTP 状态/Content-Type/响应正文片段；`Authorization/Cookie/Accept-Enckey/Token` 一律脱敏为 `REDACTED(len=N)`。
4. **本环境网络事实**：东财 `push2.eastmoney.com` 连续返回 `RemoteDisconnected / Empty reply`（HTTP 000），属**本沙箱出口**现象，不能断言公网不可用；新浪、上交所官网、深交所官网、北交所官网、巨潮 `webapi.cninfo.com.cn`、中证指数官网均可达。
5. **工具 bug 修正记录**：首轮探测脚本误用 pandas 3.0 已移除的 `to_json(default=...)`，导致成功调用被误记为 error；已改为手动序列化并重跑，本报告的"成功/失败"以重跑结果为准。

## 四、第四项：分类覆盖基数设计

设计产物见 `classification_coverage_design.json`（设计态，未实现）。核心口径：

- **分母**：全部有效 A 股（存量、非退市），取交易所官网三市去重合计 = **5580**，状态 `proven_by_exchange_official_lists`。
- **分子**：有分类记录的股票数。当前真实库 `stock_info` = 0 行、无分类表（见 D3-0 `sql_evidence.json`），分子不可得 → `unavailable`。
- **契约**：`coverage_rate = 有分类数 / 全市场基数`；分母无法确定时整个覆盖率返回 `unavailable`，**严禁用样本数冒充全市场**；分母与分子必须同一时点名单；一股多标准按选定唯一标准计一次；分类需在生效日期区间内且未过期方计为有效分子。
- **每股必备字段**：code、classification_standard、classification_value、classification_code、effective_date、source、last_update_time、status(ok/stale/unknown)。
- **V1.0 唯一标准候选**：巨潮行业分类标准（008002）——唯一实测支持 `start/end` 区间回溯历史、含四级行业层级与分类代码的来源；但时效止于约 2019-2021，当前完整性 `unknown`，故状态为 `candidate_pending_freshness_proof`。
- **过期阈值**：`stale_threshold_days = unknown`（未定，需业务确认）；确认前所有分类记录新鲜度按 unknown 处理，不得标 ok。
- **覆盖率输出 schema**：当前 `with_classification/unknown`、`coverage_rate=unavailable`，并披露"需先完成分类入库与时效固化"。

### 未证实
- 东财系全部名单/指数接口（本环境网络不可达）。
- 同花顺行业指数日线与目录（页面结构失效）。
- 腾讯全市场股票名单接口（AKShare 无对应函数）。
- 申万个股成分映射（承接 D3-0）。

### unknown
- 北交所退市名单接口是否存在。
- 沪深名单数据更新时间/新鲜度。
- 停牌状态的权威标识字段。
- 指数日线成交量/额的单位量纲。
- 分类数据时效（`freshness_status=unknown`）与过期阈值。

### unavailable
- 当前全市场分类覆盖率：分子不可得，返回 unavailable（分母=5580 已证实）。
- 行业板块指数日线覆盖率：无可稳定来源，返回 unavailable。

### 推测
- 中上协标准（008001）2024 记录可能为巨潮换代标准（承接 D3-0，待查）。
- 新浪 spot 5579 vs 5580 的 1 只差额源于时点/口径微差（未逐只定位）。

## 八、启动 D3-1 仍缺的具体依赖

1. **名单入库**：将三市 5580 只基准名单（代码/名称/市场/板块/上市日期）入库为 universe 基准表——**本轮禁止写库，未做**。
